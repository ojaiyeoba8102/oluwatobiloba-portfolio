# Oluwatobiloba — COS 106 Portfolio

A responsive, multi-page academic portfolio built with semantic HTML, external CSS and vanilla JavaScript.

## How to run
Open `index.html` in a browser, or open this folder in VS Code and select **Open with Live Server**. No build tools required. Google Fonts needs an internet connection; local fallback fonts are provided.

## Pages
- Home: student profile photo, welcome, biography, audio introduction
- About: education, career goals, skills, interests
- Projects: three concepts from Oluwatobiloba’s original materials, with functioning demos
- Planner: add/complete/delete tasks, progress bar, localStorage persistence, study table
- Contact: required-field, email and digits-only phone validation (demo only, no sending)
- Demos: calculator, travel wishlist, fashion favorites

## Source and accuracy
Profile photo, audio, original project illustrations and personal details were taken from the supplied ZIP. The travel journal and fashion favorites are newly built **sample demonstrations**, not claims that Oluwatobiloba previously completed those applications. Fashion collections are fictional. No email, phone, prior schooling, or academic achievements were invented. Contact validation is client-side only and does not send messages.
